# Archive

Files the game no longer loads, kept for reference. Nothing in `index.html`, `js/` or `css/` points here.

| File | What it is |
|---|---|
| `dallah.jpg` | Full-size pixel-art cosmic dallah (coffee pot). Unused in the game. |
| `icon.svg` | Earlier vector app icon. `hub.yaml` uses `../icon.jpg` instead. |
| `generate_falafel.py` | Script that drew the old SVG falafel clicker, since replaced by `falafel.webp`. |

The full-resolution JPG originals of the in-game art (`falafel`, `merchant`, `ascension`,
`cosmic_shovel`, and the boss portraits) were replaced by sized WebP files; they remain in
git history (`git show 3b597d0:merchant.jpg > merchant.jpg`).
